# Pandas from Dictionary to Clean CSV

Two Jupyter notebooks that take a beginner to confident, independent pandas use.

| File | Purpose |
|---|---|
| `Pandas_Course_From_Dictionary_to_Clean_CSV.ipynb` | The full lesson: 15 modules, about 10 hours. Worked code with explanations, decision guides and "Try it" prompts. Saved with outputs, so you can read it before running it. |
| `Pandas_Workout.ipynb` | 32 practice tasks + 1 challenge on a new dataset, with self-checks. Solutions at the bottom. |

## Quick start
1. Install Python 3.10 or newer
2. `pip install -r requirements.txt`
3. `jupyter notebook` (or open the files in VS Code or JupyterLab)
4. Open the lesson first, run cells top to bottom (Kernel > Restart & Run All), then do the workout.

The lesson creates an `output/` folder with `sales_clean.csv`, a data dictionary and a summary chart.
